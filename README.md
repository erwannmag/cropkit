# 🖼️ CropKit

![Version](https://img.shields.io/badge/version-v1.0.0-blue)
![Vercel](https://vercelbadge.vercel.app/api/erwannmag/cropkit)

CropKit is a NASA-compliant document slicing tool for interactively cropping structured exam sets and image-based documents — built with React, Vite, and TypeScript.

---

## 🚀 Live Demo

🔗 [cropkit.app](https://cropkit.app)

Drag and drop multi-page images. Draw horizontal cut lines. Export exact coordinates to JSON. No install required.

---

## ✨ Features

- 🧲 **Drag & Drop** multiple images directly
- 🔁 **Page navigation** (prev/next per image)
- 🟥 **Click to add/remove** red horizontal cut lines
- 📤 **JSON export** of coordinates per page
- 🧠 Scales precisely on high-DPI assets
- ⚡ Powered by Vite + React + TypeScript
